# Project Aurora

Build a modern, responsive, professional personal portfolio website for a B.Tech 1st Year Computer Science student. The website should have a clean UI, smooth animations, attractive color palette, mobile responsiveness, and excellent user experience. Use modern web design principles with glassmorphism, subtle gradients, hover effects, and smooth scrolling.

Website Title:
"Shivam Garg | Personal Portfolio"

General Requirements:

* Fully responsive for desktop, tablet, and mobile devices.
* Modern navigation bar with smooth scrolling.
* Professional typography and spacing.
* Attractive hero section with animated elements.
* Smooth transitions and scroll animations.
* SEO-friendly structure.
* Fast loading and optimized performance.
* Dark mode and light mode toggle.
* Professional footer with social media links.
